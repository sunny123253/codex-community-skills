这份参考只描述本机已确认的运行环境，便于复用流程；新项目仍须遵守项目自己的环境规则。

- Python 环境：`E:\app\anaconda\envs\env_skill`
- GSAS-II 官方源提交：`01cfedb09190dd443121e91a935d77930171ca99`
- 已核验版本组件：Python 3.10.18、NumPy 2.0.1、SciPy 1.15.3
- GSAS-II 的 GUI、脚本接口和编译模块在该环境可加载。

本机的“闲聊”工作区和博士论文静态反应子项目已经在 README 中确认 `env_skill`，后续直接沿用。对于新的项目，先检查环境标记、README 与记忆；不明确时查询 `E:\app\anaconda\Scripts\conda.exe env list` 并按用户规则确认环境，确认后写入该项目 README，避免重复询问。

含中文路径的检查工具已用该环境的 `python.exe -X utf8` 直接运行成功；本机 `conda run` 的 GBK 输出包装曾与 UTF-8 子进程输出冲突，必要时改用已确认环境的解释器，或先统一该进程的输出编码。编译模块加载失败时检查该环境的 DLL 搜索路径，不切换到系统 Python。

已用 `HUANGHESE` 案例验证以下情形：正常的正值低阶球谐模型、负反射择优取向修正模型、角度范围内负峰宽模型，以及未收敛模型。正常案例的石膏/方解石结果约为 87.8/12.2 wt.%；这是两相归一化的初步估计，存在 20.56° 未归属峰和明显强度残差，不能作为整个样品的绝对含量或最终精确定量。

检查工具还用带排除区间的真实 GPX 验证：18 个排除点应正确移出统计，独立复算 Rwp 为 17.0005883963%，保存的直方图统计为 16.9161174933%；应报告不一致和未收敛，不能把被掩码数据填成 NaN 后参与求和。

本机案例的原始文件位于博士论文主项目下；复用时传入实际 GPX 路径。已有含量数值和路径都不作为新样品的默认值。检查工具在成功结束时核对原文件 SHA256，保护原始数据与已有项目。

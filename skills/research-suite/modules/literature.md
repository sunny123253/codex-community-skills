# 文献检索与综合

先确定用户要快速查找、个人库证据、领域现状、系统综述还是跨论文综合。普通问题按所需深度完成，不默认扩成完整综述。

## 来源与检索

- 个人库或本地论文：优先现有 Zotero/MinerU MCP，记录 Zotero key、文件、章节/行位置；遵守 `kb-agent` 的只读和写入边界。未授权子代理时由当前代理完成，不启深检索子代理。
- 工具不可用但本地 API 可用时，按 [本地库辅助工具](../references/resources.md#本地文献工具) 使用只读 helper。Zotero 9.0.6 不使用已知异常的 `qmode=everything`。候选和长文本必须按返回游标续读，不能把截断结果称为全面检索。
- 外部检索使用实际可用的学术连接器/API，并依研究领域选择来源。用户限定本地库时不得默默补外部证据；本地与外部证据分开标识。普通非本地限定的文献检索可以使用公开来源。
- 文献身份按 DOI、其他可靠标识符和规范化题名去重，区分预印本、正式版、原文与译文。相关性与证据质量优先，不按期刊名、作者地位或引用数替代内容筛选。
- 需要专门检索、格式转换或严格他引审计时，按 [专项工具](../references/resources.md#学术检索与引文工具) 读取相应流程，不声称旧资料中的工具已接入。

## 问题驱动的深度研究

把宽主题转为几个可回答的问题，例如“哪些条件控制现象”“相反结论能否由条件差异解释”“现有证据能区分哪些机制”。从主流解释、反证、邻近学科和方法/测量偏差选择相关视角，串行或按已授权方式检索。视角是查漏方法，不是规定每个课题都要搜五类。

保存必要的检索范围、日期、关键词、纳入条件和候选去留理由。系统综述才执行相应系统性筛选与报告规范；普通叙述综述不伪称系统综述。

## 从逐篇摘要到综合

为每篇文献提取：它回答的问题、证据类型、关键发现及其定位、适用条件、未解决问题。按机制/问题组织段落，把多篇研究放在同一个论点中比较。主题可多标签，不强迫耦合现象互斥。

比较表字段由问题决定。反应输运常需温压、矿物组成、入口化学、应力、几何、流量/压差、时间尺度、观测和模型假设；只填已读原文明示的信息。缺失写未知，不能由领域常识补齐实验参数。

出现相反结论时比较条件、测量定义、空间/时间尺度、控制与误差，而不简单平均，也不强选支持原假说的一边。归一化或合并数据前核对定义与单位；无可比性时分组讨论。明确哪些是作者结果、哪些是本次综合推断。

## 停止与交付

围绕研究问题检查关键流派、近邻工作与反证是否覆盖；补搜针对具体缺口。新增检索不再改变判断且目标已满足时交付，保留不能回答的问题。证据不足就缩小结论，不用文献数量配额或循环检查拖延。

答案先给有证据支持的判断，再展开比较。完整综述需要连贯正文、条件比较和可追溯参考文献；研究者工作报告可保留未知标记，可投稿正文则将关键缺口放在附注或工作表中。按用户要求保存，不能默默写回库。

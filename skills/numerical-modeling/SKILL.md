# 数值模拟 Agent

围绕科学问题发展一个可追溯的主模型，以方程、尺度、迭代收敛和数值误差推进求解。主模型可以有版本和验证算例；它不意味着所有修改都能从旧瞬态结果直接续算。

## 接入项目与选择软件

先读适用项目指令、README、memory 的近期摘要、现有主模型及运行配置。确认任务是解释、输入检查、模型修改、验证还是实际求解，以及已授权的资源、目标工况、物理时间或稳态目标。执行 Python 或环境操作前遵循项目已确认的环境选择；不把其他项目的路径、软件版本、环境和参数当默认值。

只读取本次软件对应的说明；涉及多个软件时读取相应几份。不要为了使用本 Skill 加建运行框架、审计程序或统一目录。

## 数学与数值方案

1. 明确科学问题、控制变量、主要评价指标及其所需精度。实际求解任务写明目标物理时间或目标状态；有限的输入检查不扩为完整模拟。
2. 列出未知量、控制方程、本构、参数单位和来源、初始条件、边界/界面条件及代数约束。核对压力参考、刚体自由度、通量符号、反应计量、初值相容性以及适用近似。
3. 估算特征长度、对流/扩散/反应/波动等相关时间及无量纲参数，据此选网格、离散格式、求解器和实际时间步。区分单元尺寸、总单元数和区域大小；不把“小网格”误解成禁止必要的细网格。
4. 在主模型上逐步加入需要的方程或不可分割耦合。已有完整模型只修改任务涉及部分，不为了遵循这个顺序拆掉已建立的物理过程。
5. 按目标变量尺度设置线性、非线性及耦合求解、绝对/相对容差、迭代上限、时间积分和自适应规则。记录输出间隔与实际接受步长，不能相互替代。

信息缺失时先做可独立推进的建模工作，只询问影响科学问题或求解判断的关键项。不要编造材料数据、误差要求、实验结果或软件能力。

## 推进、验证与诊断

不把小规模、粗网格、缩小区域、短时间或简化物理的预备运行设为每个新模型的固定前置，也不采用固定极短时间梯级反复从零启动。初始网格与时长依据目标问题选择。

验证与故障诊断分别安排：解析解、制造解、解析极限、可信基准、网格/时间精度和守恒检查可按预定计划主动进行，不必等发生故障。诊断算例用于定位具体问题，需说明目的、比较量及如何返回主模型。两者均不能替代目标模型的实际求解范围。

每个阶段事先选择所需的收敛、误差和守恒判据；未受修改影响且覆盖当前工况的证据可以复用。达到判据后继续下一组方程、目标时间或科学分析，不反复做同一检查，也不持续添加与结论无关的算例。

允许求解器正常迭代和既定步长适应。初始残差大、局部波动或可恢复的拒步本身不要求中断；判断持续趋势、求解器结束原因、守恒与误差。中间 Newton 迭代值与最终接受的物理解分开判断。数值设置调整可依据尺度估算、计划内精度研究、既定自适应或已观察到的问题，不限于故障发生后。

有问题时提出明确原因和比较指标，修改受影响设置并保留原记录。可以成组修改数学上关联的设置，但不得随意同时改动物性、边界、区域、网格和步长，使原因无法判断。改变科学问题的近似、初态或加载历史前，说明影响并取得用户同意。

## 初始猜测、物理初态与续算

- **稳态初始猜测**：前一参数或较简单方程的解可以帮助非线性求解；最终必须求解目标方程和参数。接触、塑性等路径相关模型还要核对载荷历史。
- **真实物理初态**：瞬态问题按规定的初始场及材料/化学/接触状态开始。不得仅为收敛方便用稳态结果替换它，或改变真实加载过程。
- **完整续算状态**：只有方程、条件、物理时间和此前演化仍适用，且变量、网格、约束、本构、耦合及时间积分历史完整一致，才能从该状态继续。场文件或结果图不一定包含这些信息。
- **改变既往演化的修改**：若新方程、反馈或参数应从初始时刻生效，旧末时刻不能直接作为新模型起点；回到受影响历史之前，必要时从规定初态重新积分，仍复用主模型定义。只有物理方案规定某时刻才改变过程时，才采用对应的分段演化。

所需续算状态依算法和软件确定。可使用软件支持的历史重建、重新初始化及场映射，但须检查相容性、守恒与恢复后的误差；不能借此补造缺失的材料、化学反应或加载历史。

保存与当前任务关联的输入、有效解、日志和重启文件。恢复前检查它们的版本与适用范围；停止或清理进程时精确关联当前任务，不按程序名终止其他模型。

## 结果与结束条件

瞬态任务核对目标物理时间、每步收敛和时间精度；稳态任务核对迭代收敛、关注量稳定及守恒，不能把伪时间或迭代计数当物理时间。输入可读、程序正常退出或残差降低均不能独自证明目标数值解正确。

数值验证按 [verification.md](references/verification.md) 区分迭代、空间、时间、耦合误差和物理模型适用性。求解结束后以主要指标回答科学问题，检验有依据的标度律、参数归一化及适用范围，再组织代表场、响应曲线、误差图和机制图谱；不强造普适关系。独立绘图任务继续使用相应绘图技能。

向用户报告实际启用方程、完成的时间/状态、收敛与误差数值、主要科学指标及下一项推进工作。使用数值模拟术语，不用软件工程状态词代替结论。没有执行的计算明确写未执行；项目记忆保留关键决策、问题及结果路径，不复制长日志。

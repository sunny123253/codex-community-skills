# CMG GEM 操作

项目目录、GEM 版本、可执行程序、执行环境和输出布局从当前 README、memory 和安装手册确定，不使用旧项目路径、环境或水化学数值作默认值。

## 输入与依赖

保留主 deck、include、物性/网格数组、流体与岩石表、矿物/水相及井控的依赖关系。只复制单个 `.dat` 到输出目录可能丢失相对 include；应保留依赖树，或用目标版本支持的数据/工作/输出目录参数保持可解析的完整路径。

| 修改项 | 同步检查 |
| --- | --- |
| 流体组分 | `NC`、名称、分子量、临界参数、相互作用、注入组成与输出组分 |
| 水相物种 | 数量、名称、分子量、电荷、离子尺寸、扩散、初始浓度及计量的顺序 |
| 矿物与反应 | 数量、名称、摩尔体积、反应计量、初始库存、速率与输出 |
| DPDP 与裂隙 | 双重介质开关、基质/裂隙数组、渗透率、几何尺寸、交换因子 |
| 日程 | 实际时间、最大步长、注入/关井顺序及最终停止条件 |

不同输入版本的关键字与表结构按当前手册核对。不要无依据合并化学组分或修改原始物性。mg/L、mol/L 与 mol/kg 水之间的转换需有溶液/溶剂质量、密度和盐度依据，不能统一假定密度为 1 kg/L。

## 执行与监测

使用已确认程序和该版本支持的输入参数。GEM 常见调用需 `-f` 标明数据文件；无前导选项可能进入交互等待。`-checkonly`、工作/数据目录及 restart 参数需从实际版本帮助或手册核实后使用。[^1]

输出置于项目要求的位置，记录本任务输入、工作目录、命令、进程身份、`.out`、`.log`、`.sr3` 或其他结果及重启文件。运行时区分：

- 输入解析：错误数量及警告含义，不能把全部警告视为致命错误。
- 求解推进：实际模拟时间、Newton/线性迭代、接受步长、步长削减与拒步。
- 数值质量：物质收支、解析/基准误差、网格/步长及相关科学指标。
- 正常结束：目标版本的正常终止标识，例如 `STOP GEM ... End of simulation` 或 `End of Simulation: Normal Termination`，并核对实际目标时间/日程。

初始残差、可恢复的时间步削减或一次收敛重试不自动构成失败。持续异常或具体错误需要有依据地定位；输入可启动不等于长期模型完成。用户只检查输入时完成该有限范围，实际建模求解任务持续推进目标时间及科学分析。

## 重启与进程范围

按当前版本设置并保存真正的 restart 文件。已核对的 GEM 2023.40 手册明确 restart 信息写入 `.RST`，`.SR3` 或 `.IRF/.MRF` 不能替代它，且需正确识别父运行结果；其他版本按其手册确认。[^2]

恢复前核对 deck、日程、组分/矿物顺序、父运行、物理时间及完整状态是否仍适用。改变应从早期生效的反应或反馈时，不能仅在旧结果末时刻开始新过程。

停止或清理必须通过本任务 PID、命令行、输入路径或任务标识确认归属，不终止全部同名 GEM 进程。保留失败及最后有效状态，避免重复从零启动。

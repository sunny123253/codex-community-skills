# 学术表达：聚焦贡献、减少防御、自然行文

本模块融合反防御写作和 Humanizer 的有用方法，目标是更清楚地表达真实研究。顺序是科学含义 → 论证与段落 → 文体和作者声音 → 句子。只要求语言润色时，不能擅自更换论点或研究操作。

## 1. 先保护科学含义

修改前识别并在修改后核对：数值、范围、正负号、单位、公式和变量、引文及其对应主张、比较对象、实验/模型条件、否定、因果关系和不确定性。术语保持一个概念一种名称，不能为词汇多样性把同一技术对象不断换名。

纯语言修改可直接完成；已授权的结构重写可合并和重排段落。涉及科学含义的调整需在简短说明中明确列出，未获证据支持的加强不进入正文。不要为了“更专业”把测量改成标定、表征改成解耦等不同操作。

## 2. 聚焦真正成立的贡献

明确问题、核心发现或方法增量以及支持它的最强证据。按论证职责组织研究，不写成先做什么、后来失败什么的流水账。与有效性、解释和复现无关的操作过程可移到工作记录。

相关负面结果、关键反证、必要对照和方法限制不能因不利于故事而删除。遇到不占优结果，先问它检验了什么主张、是否存在有证据支持的权衡；不编造失败原因，不暗换评测口径。证据不支持原故事时，缩小或更改主张。

## 3. 减少防御，保留必要限定

对可疑句子做必要性判断：删除后是否会让读者误解有效性、证据解释、适用范围、研究设计或复现方法？若会，保留或等义地简化；若仅是在回答假想批评，删去或改成正面的范围陈述。混合句保留技术条件，删去自我辩护。

常见修复：

| 问题 | 修复方式 |
|---|---|
| 反复说“不主张、不证明、不意味着” | 在结论附近准确说明实际研究范围，避免重复 |
| 多重 may/might/potentially 或中文“可能一定程度上” | 保留真实的不确定性及其来源，去掉重复限定 |
| “为确保公平”“为避免误解”等自我辩护 | 直接说明控制变量、定义或条件 |
| “效果仍令人鼓舞”等补偿性评价 | 给出真实观察、误差或权衡，没有依据就不补解释 |
| 将局部弱项写成普遍失败 | 报告该项结果及其具体范围，不扩大否定 |

证据扎实时不自动降成“可能”；证据有限时也不把 suggests 换成 proves。必要的 only、under、may、not 不是禁词。条件对核心结论至关重要时，可在摘要、引言或结论保留，不能机械移走。

示例（仅演示表达，不提供新的科学结果）：

“为保证公平，我们强调所有试验均在相同入口条件下开展。” → “所有试验采用相同入口条件。”

“现有数据可能在一定程度上提示压溶参与闭合，但并不意味着它是唯一机制。” → “现有数据提示压溶参与闭合；其他机制尚未排除。”若未排除解释影响中心结论，后半句保留。

## 4. 去掉机械表达，保持学术语气

删除无信息的意义拔高、宣传形容词、伪深度尾句、重复总结、没有内容的过渡和模板化开场。把“发挥重要作用”“为……奠定基础”等换为材料中真实存在的具体作用，不能为了具体而补造事实或数字。

英文关注重复 Moreover/Furthermore、无信息的 -ing 尾句、刻意回避 is/has、强凑三项、无来源的 experts argue 和抽象名词堆叠。中文关注“随着……不断发展”“具有重要意义”、多层“的”、“进行+动词”、缺主语、四字词排比和反复“不是X而是Y”。只有妨碍含义和阅读时才改，不按词表机械替换。

根据论点调整句长和节奏，拆开多层从句，保持真实逻辑。转折、被动语态、第一人称复数、专业搭配和必要重复可保留。使用研究者的自然、克制声音，不注入闲聊、虚构经历、幽默或人为拼凑的“个人风格”。

不承诺通过 AI 检测，不用“人类率”评分，不把去AI味当成隐藏作者贡献或披露的工具。除非用户另有要求，结果就是清楚准确的学术文本。

## 5. 文体与输出

论文用证据支撑发现；研究方案以科学问题、可行路径和真实前期基础支撑目标，保留合理愿景。修回信对真实审稿意见作答，可以解释取舍，不能套用“删去所有反对意见”的正文策略。

按用户请求保留、压缩或重构篇幅。默认先给修改文本，再简短说明实质改动和仍需事实判断的地方，不强制输出检测报告。翻译先理解原意再组织目标语言，不增加因果性、普适性或已实现程度。期刊句式资源按需读取，不把某期刊习惯当科学正确性标准。
